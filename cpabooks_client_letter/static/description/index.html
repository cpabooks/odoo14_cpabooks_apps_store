Good to know
Can I change the wording?
Yes. Edit any letter type, or edit a generated letter and save it as a new template.
Does it need other apps?
Only standard Odoo: CRM, Sales, Invoicing, Project and Discuss. No third-party modules.
Can I start from a blank page?
Yes. Pick "Blank Letter" and write freely. Your company letterhead is still applied.
Do estimations work?
Yes, if you use an estimation app that provides job.estimate. It is detected automatically and not required.
