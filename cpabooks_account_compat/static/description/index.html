CPABooks Account Compatibility

Technical module used by CPABooks accounting apps on Odoo 19 (Chart of Accounts Management, Audited Financial Statements). It is installed automatically with them.

  • Account types (Receivable, Payable, Bank and Cash, Current Assets ...) linked to the Odoo 19 account type of each ledger.
  • Company, deprecated and account group fields on ledgers, kept in sync with the standard Odoo 19 fields.
